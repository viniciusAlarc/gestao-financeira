3. **Correção do falso positivo (caso b):** um caminho relativo pode vir ancorado numa base
   externa citada junto. A base é procurada na **mesma janela de contexto que a `RE_HISTORICA` já
   usa** (linha anterior + linha do match) — precisou ser assim porque o `AGENTS.md` quebra a
   frase em duas linhas:

```python
RE_BASE_LOCAL = re.compile(r'`(~/[^`\s]+)`')

def caminho_existe(c, bases_extras=()):
    c = c.lstrip('./').rstrip('/')
    if c.startswith('~'):
        return os.path.exists(os.path.expanduser(c))
    bases = [os.path.join(RAIZ, r) for r in RAIZES] + list(bases_extras)
    return any(os.path.exists(os.path.join(b, c)) for b in bases)
```

No laço, `ini`/`fim` (já calculados para a `RE_HISTORICA`) passaram a alimentar também
`RE_BASE_LOCAL.findall(texto[ini:fim])`, e `caminho_existe(c, bases_extras)` tenta as raízes do
repo **e** as bases da frase. Sem as bases, o caminho segue sendo cobrado normalmente — a prova é
o achado 7 continuar aparecendo.
