## 2. Achados principais

| Achado | Fonte |
|---|---|
| A API é **exclusiva de pessoa jurídica** | `docs/introducao/como-criar-uma-aplicacao`: "O acesso às APIs do Inter é exclusivo para clientes pessoa jurídica." |
| Cobre **saldo, extrato (simples, enriquecido e PDF), pagamentos (boleto, DARF, lote, Pix) e webhooks** | `docs/introducao/nossas-apis` + referência Banking |
| Extrato: **máximo de 90 dias por consulta**, escopo `extrato.read`, 10 chamadas/min, token de 60 min | referência `/extrato` e `/saldo` |
| **Não existe API de cartão de crédito** na lista oficial de APIs | `docs/introducao/nossas-apis` |
| A API **paga boleto** por código de barras, mas **não lista boletos a pagar** nem de outra titularidade | referência `/pagamento` e API Cobrança |
| **Open Finance não é caminho para app pessoal**: só instituições financeiras, de pagamento ou autorizadas pelo BCB recebem dados | `openfinancebrasil.org.br/perguntas-frequentes` |
| O extrato enriquecido tem `idTransacao`; o simples **não tem id** — e o modelo não tem campo para isso | referência `/extrato` e `/extrato/completo` + `financas/models.py` (lido, não alterado) |
| O portal hoje lista **SDK Python** (além de Java, C#, PHP) — a descoberta de 01/11 dizia "só Java e C#" | `docs/sdks/sdk-python` |

## 3. O que a importação consegue preencher no `Movimento`

Preenche `data`, `valor`, `tipo`, `descricao` e `origem=inter`. **Não** preenche `conta` (vínculo fixo a
decidir), `categoria` (a API não tem categoria e o modelo exige uma) nem `criado_por` (a API não tem
autor). A chave antiduplicidade que a fase 7 exige não existe no modelo hoje.
